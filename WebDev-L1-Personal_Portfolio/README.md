## 📌 Project Overview
A modern, professional, and fully responsive Personal Portfolio Website designed and developed for **Priyo Ghosh**, a Full-Stack Web Developer. 

The portfolio showcases development skills, technical stack, featured projects, background, and contact avenues with an emphasis on clean layout fundamentals, visual hierarchy, polished typography, and responsive UX.

---

## 🎨 Design System & Aesthetics

### Color Palette
- **Primary:** `#2563EB` (Vibrant Royal Blue — Primary CTAs, active states, brand accent)
- **Secondary:** `#60A5FA` (Sky Blue — Highlights, gradients, sparkle accents)
- **Dark:** `#0F172A` / `#0B1120` (Deep Slate Navy — Hero, Sticky Nav, Footer)
- **Text Primary:** `#0F172A` / `#FFFFFF` (High contrast text)
- **Text Secondary / Muted:** `#334155` & `#64748B` (Readable body text)
- **Backgrounds:** `#FFFFFF` (Clean primary sections) & `#F8FAFC` (Light secondary section contrast)
- **Border:** `#E2E8F0` / `rgba(255, 255, 255, 0.1)`

### Typography
- **Primary Font:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (Modern, geometric, highly legible sans-serif)
- **Accent Handwritten Font:** [Caveat](https://fonts.google.com/specimen/Caveat) (*“Turn ideas into reality”* hero annotation)

## 🚀 Key Sections & Features

1. **Sticky Top Navigation Bar**
   - Distinct **PG** monogram brand logo + name.
   - Smooth-scrolling anchor navigation links (`Home`, `About`, `Skills`, `Projects`, `Contact`).
   - "Download CV" action button.
   - Dynamic glassmorphism backdrop blur on scroll.
   - Responsive mobile navigation drawer with hamburger toggle.

2. **Hero / Profile Section**
   - Dark theme matching the visual design mockup.
   - Friendly greeting (`👋 Hello, I'm`), prominent headline with gradient text.
   - Role subtitle: *Full-Stack Web Developer*.
   - Professional biography and dual CTAs: **View My Work →** and **Contact Me**.
   - Social links: GitHub, LinkedIn, and Email.
   - Professional developer portrait set against an ambient blue radial glow.
   - Handwritten decorative note: *“Turn ideas into reality ⤶”*.
   - Floating stats card: **1+ Years Learning | 10+ Projects | Always Learning**.

3. **About Me Section**
   - Clean two-column layout.
   - Background narrative on engineering interests and lifelong learning.
   - Information card displaying Name, Email, Location (Dhaka, Bangladesh), and Availability status (*Open to opportunities*).

4. **Skills Section (12 Technologies)**
   - Responsive CSS Grid featuring 12 key frontend, backend, database, and tool competencies:
     - **HTML5**, **CSS3**, **JavaScript**, **React**, **Next.js**, **Node.js**, **Express**, **MongoDB**, **MySQL**, **Git**, **Tailwind CSS**, **Figma**.
   - Custom SVG brand icons, crisp card containers, and smooth hover elevation.

5. **Featured Projects Showcase**
   - **Antix – Ice Cream Landing Page** (HTML5, CSS3, Responsive Design)
   - **Personal Portfolio** (HTML5, CSS3, Responsive Design)
   - **E-Commerce Website** (HTML, CSS, JavaScript)
   - Each card includes thumbnail with hover zoom, description, technology pills, and direct links (**Live Demo ↗** and **GitHub ↗**).

6. **Contact Section & Interaction**
   - Direct contact details with prominent **Send Me an Email** button with sparkle accents.
   - Functional interactive contact form with real-time validation and instant feedback.
   - Toast notification system for user actions.

7. **Footer**
   - Consistent dark slate navy styling.
   - Brand monogram, mission tagline, quick navigation links, and copyright notice.

---

## 📱 Responsive Layout Details
The site is built mobile-first and fluidly adapts across all viewport sizes:
- **Desktop (1200px+)**: Spacious two-column hero, 6-column skills grid, 3-column projects grid.
- **Tablet (768px – 1024px)**: Stacked hero, 3/4-column skills grid, 2-column projects grid, compact spacing.
- **Mobile (< 768px)**: Centered hero, single-column about, 2-column skills grid, single-column projects, slide-in mobile navigation drawer.
