* **Admin Login**: **[https://onlinepizzadeliverystore.vercel.app/admin/login](https://onlinepizzadeliverystore.vercel.app/admin/login)**

React 19 + Vite frontend application for the PizzaHub Delivery Application.

## Key Features
- **Pizza Builder Wizard**: 4-step interactive pizza customizer with live price computation.
- **Real-Time Tracking**: Socket.IO client and auto-sync polling for live delivery stage tracking.
- **Admin Control Panel**: Real-time kitchen dispatch and inventory controls.
- **Responsive UI**: Custom design system built with modern vanilla CSS and Lucide icons.

## Scripts
- `npm run dev`: Start local Vite development server (proxies `/api` to port `5000`)
- `npm run build`: Compile production distribution bundle
- `npm run preview`: Preview production build locally
